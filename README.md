### A GUI for the `papirus-folders` script

This program is designed for visually changing the color of folders within the installed [Papirus](https://github.com/PapirusDevelopmentTeam/papirus-folders) icon theme.

**Dependencies:** gtk2 (or `libgtk2.0-0` on Debian)

Download and extract the [papirus-folders-gui.tar.gz](https://github.com/AKotov-dev/papirus-folders-gui/raw/refs/heads/main/papirus-folders-gui.tar.gz) archive. Run the **StartAsRoot** file (you will need to provide the root password to execute it with root privileges).
