### A GUI for the papirus-folders script

This application lets you change folder colors in the installed [Papirus icon theme](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme).
  
The application updates all three themes: `Papirus`, `Papirus-Dark`, and `Papirus-Light`.

**Dependencies:** gtk2 (or `libgtk2.0-0` on Debian)

- Download and extract the [papirus-folders-gui.tar.gz](https://github.com/AKotov-dev/papirus-folders-gui/raw/refs/heads/main/papirus-folders-gui.tar.gz) archive
- Run the **StartAsRoot** file (you will need to provide the root password to execute it with root privileges)
- To see the result, reopen any file directory or right-click on an empty area of ​​the desktop
- **Note:** The [papirus-folders](https://github.com/PapirusDevelopmentTeam/papirus-folders) script (v1.14.0) is already included in the archive
